## 🌌 About The Game

**STAR DEFENDER** is a lightweight, arcade-style space shooter developed entirely in Python using the Pygame library.

Take control of a futuristic spaceship, fight against waves of incoming enemies, collect points, and test your survival skills as the difficulty increases.

Inspired by classic arcade space shooters, STAR DEFENDER combines simple mechanics with an engaging gameplay experience and a clean visual design.

One mission. Endless enemies. How long can you survive?

---

## ✨ Features

- 🚀 **Smooth Movement** — Control your spaceship using keyboard inputs.
- 🔫 **Shooting System** — Fire projectiles to eliminate incoming enemies.
- 👾 **Enemy Spawning** — Face continuously spawning enemies.
- 📈 **Progressive Difficulty** — The challenge increases as your score grows.
- ❤️ **Health System** — Manage your three lives carefully.
- 🏆 **Score Tracking** — Earn points for every enemy destroyed.
- 🌠 **Animated Starfield** — Enjoy a moving space background.
- ⚡ **60 FPS Gameplay** — Smooth arcade-style performance.
- 🔄 **Restart System** — Jump straight back into the action after defeat.

## 🎮 Gameplay

Your mission is simple: survive as long as possible.

1. Move your spaceship around the screen.
2. Shoot incoming enemy ships.
3. Avoid collisions and enemies reaching the bottom of the screen.
4. Earn 10 points for every enemy destroyed.
5. Survive as the enemy waves become increasingly difficult.

**The game ends when your health reaches zero.**

## 🕹️ Controls

| Key | Action |
|:---:|---|
| `W` / `↑` | Move Up |
| `S` / `↓` | Move Down |
| `A` / `←` | Move Left |
| `D` / `→` | Move Right |
| `SPACE` | Shoot |
| `SPACE` | Start / Restart |
| `ESC` | Exit Game |

## ⚙️ Installation

### Requirements

- Python 3.10 or newer
- Pygame

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/star-defender.git
```

### 2. Navigate to the Project

```bash
cd star-defender
```

### 3. Install Dependencies

```bash
pip install pygame
```

### 4. Launch the Game

```bash
python star_defender.py
```

That's it! You're ready to defend the galaxy. 🚀

## 🎯 Project Goals

STAR DEFENDER was created to demonstrate how a complete arcade-style game can be developed using Python and Pygame.

The project explores several fundamental game-development concepts:

- Game loops and frame-rate management
- Object-oriented programming
- Collision detection
- Keyboard input handling
- Dynamic difficulty systems
- Sprite rendering using geometric shapes
- Basic game-state management
